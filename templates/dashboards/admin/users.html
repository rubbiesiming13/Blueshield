BlueShield Access Structure

User roles determine access to BlueShield functions and information.

Division Officer

Records complaints, suspects, cases, investigations and operational information within the officer's assigned area.

Division Admin / Prosecution

Reviews submitted case files and manages prosecution-related processing.

Police Station Commander

Oversees operational records and officers assigned to the police station and district.

PPC / System Administrator

Province-wide administrative access including users, stations, records, reporting and system configuration.

Provincial User Administration

User accounts control access to protected BlueShield police information. Only authorised PPC / System Administrator accounts can create, modify, activate or deactivate users.
